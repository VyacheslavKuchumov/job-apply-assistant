# Job Apply Assistant

Django MVP по плану: анкета кандидата, CRUD вакансий, генерация резюме/письма/советов через локальный `pi`, чат доработок и мобильная адаптация.

## Запуск в локальной сети

```bash
cd /home/kuchumov/job_apply_assistant
./start_lan.sh
```

Адрес на этой машине: http://127.0.0.1:8000/
Адрес в локальной сети: http://192.168.1.12:8000/

## Ручной запуск

```bash
cd /home/kuchumov/job_apply_assistant
source .venv/bin/activate
python manage.py runserver 0.0.0.0:8000
```

## Что реализовано

- `/accounts/login/` — отдельная страница входа; без сессии приложение сразу редиректит сюда.
- `/accounts/signup/` — отдельная страница регистрации пользователя.
- `/accounts/logout/` — выход через Django auth.
- `/profile/` — личный кабинет/анкета кандидата, доступен после входа.
- `/vacancies/` — список вакансий текущего пользователя.
- `/vacancies/new/` — создание вакансии.
- Детальная страница вакансии с описанием, заметками, файлами PDF/TEX, результатами генерации.
- Кнопка «Сгенерировать резюме и письмо» вызывает локальную команду `pi`.
- Если `pi` недоступен или не ответил, сохраняется базовый fallback, чтобы интерфейс не ломался.
- Чат доработок на странице вакансии.
- Анкеты и вакансии разделены по пользователям.
- SQLite база для MVP.
- Адаптивный интерфейс для телефона.
